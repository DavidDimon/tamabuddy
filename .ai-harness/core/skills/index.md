# Skill routing

Load only the skill matching the task.

| Need                                    | Skill                                                                         |
| --------------------------------------- | ----------------------------------------------------------------------------- |
| Create an implementation-ready task     | [`create-implementation-task`](create-implementation-task/SKILL.md)           |
| Build an outcome-oriented roadmap       | [`build-roadmap`](build-roadmap/SKILL.md)                                     |
| Map current desktop boundaries          | [`understand-desktop-architecture`](understand-desktop-architecture/SKILL.md) |
| Design or visually refine the desktop   | [`design-interface`](design-interface/SKILL.md)                               |
| Implement the smallest complete change  | [`minimal-change`](minimal-change/SKILL.md)                                   |
| Map current engine boundaries           | [`understand-engine-architecture`](understand-engine-architecture/SKILL.md)   |
| Find the owning change location         | [`locate-extension-point`](locate-extension-point/SKILL.md)                   |
| Implement a formalized domain rule      | [`implement-domain-rule`](implement-domain-rule/SKILL.md)                     |
| Change XState behavior                  | [`modify-state-machine`](modify-state-machine/SKILL.md)                       |
| Coordinate elapsed or multi-rule events | [`implement-processor`](implement-processor/SKILL.md)                         |
| Choose function/pattern                 | [`evaluate-pattern-choice`](evaluate-pattern-choice/SKILL.md)                 |
| Add engine tests/mocks/builders         | [`write-engine-tests`](write-engine-tests/SKILL.md)                           |
| Review semantic code smells             | [`review-code-smells`](review-code-smells/SKILL.md)                           |
| Compress engineering prose              | [`optimize-text-caveman`](optimize-text-caveman/SKILL.md)                     |
| Review a completed engine change        | [`review-engine-change`](review-engine-change/SKILL.md)                       |
| Repair architecture documentation       | [`update-architecture-docs`](update-architecture-docs/SKILL.md)               |

For multi-part work, start with retrieval/location, then load only the implementation and review skills the change needs.
