# External skill routing evaluations

| Scenario                            | Expected retrieval                                                    | Expected use                                                  | Wrong turn                                            |
| ----------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------- | ----------------------------------------------------- |
| Add a small desktop preference      | owning desktop docs; `minimal-change`; Ponytail reference             | reuse the versioned preferences adapter and add focused tests | global Ponytail mode or new state library             |
| Review an uncommitted React change  | code-smell rule; `review-code-smells`; Ponytail review reference      | concrete prioritized findings in local severity format        | copy upstream response format or style-only findings  |
| Polish the existing settings screen | desktop visual language; `design-interface`; Taste redesign reference | evidence-based targeted CSS/component changes                 | public landing-page treatment or remote stock imagery |
| Change only engine behavior         | engine domain and engine implementation skills                        | external design skill is not loaded                           | UI redesign bundled with domain work                  |

Fail when an external snapshot overrides Tamabuddy boundaries, activates hooks or session modes, introduces an unrequested dependency, or is treated as implemented product policy.
