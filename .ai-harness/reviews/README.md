# Architecture reviews

Store future review records here when they provide durable evidence. Name them `YYYY-MM-DD-short-title.md` and use [`../core/templates/review-finding.md`](../core/templates/review-finding.md).

A finding can justify a local fix immediately, but it becomes a rule or skill only through [`../core/workflows/review-learning.md`](../core/workflows/review-learning.md). Promotion needs two independent occurrences or explicit high-risk human approval, realistic validation, and recorded review status. Prefer a domain rule over a core rule when the evidence is engine-specific.
