# Mimo

## Identity

- Id: `mimo`
- Theme: companion creature
- Personality: affectionate and attention-oriented
- Primary silhouette: round companion with long floppy ears
- Primary accent: cream with pink details

## Mandatory visual anchors

- long ears descending on both sides of the head;
- round face and compact body;
- small curved mouth;
- heart motif limited to emotion and effect frames;
- soft silhouette without elemental particles.

## Stage direction

| Engine stage | Direction                                             |
| ------------ | ----------------------------------------------------- |
| `egg`        | Soft round capsule with two folded ear marks          |
| `baby`       | First guide form; wrapped or folded ears              |
| `child`      | Second guide form; long ears and small body           |
| `teen`       | Longer limbs and more expressive ear poses            |
| `adult`      | Third guide form; upright companion with heart accent |
| `elder`      | Seated, calm companion with heavier relaxed ears      |

Mimo's ears are its primary emotional channel and must remain readable without pink color.

## Production manifest

The desktop catalog implements Mimo on the shared `24 × 13` cell canvas. Every
engine stage provides the complete visual set, keeping the long ears readable
in monochrome. Hearts are reserved for emotional reactions, accepted commands
use short sequences, and reduced-motion mode keeps the first meaningful frame.
