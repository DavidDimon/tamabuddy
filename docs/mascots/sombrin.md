# Sombrin

## Identity

- Id: `sombrin`
- Theme: shadow creature
- Personality: reserved and slowly revealing
- Primary silhouette: small dark body with horn-like ears
- Primary accent: muted violet

## Mandatory visual anchors

- pointed horn-like ears;
- dark rounded head and compact body;
- bright eyes and small mouth;
- shadow wisps rather than fire-like sparks;
- later forms may reveal limbs, wings, or horns without losing the rounded core.

## Stage direction

| Engine stage | Direction                                          |
| ------------ | -------------------------------------------------- |
| `egg`        | Dark orb with two faint points                     |
| `baby`       | First guide form; minimal shadow body              |
| `child`      | Second guide form; clearer ears and small limbs    |
| `teen`       | Taller shadow with partial horn and wing hints     |
| `adult`      | Third guide form; fully revealed horned silhouette |
| `elder`      | Composed guardian form with folded shadow wings    |

Sombrin must remain friendly enough for a care game. Darkness comes from mystery and slow visual revelation, not horror imagery.

## Production manifest

The desktop catalog implements Sombrin on the shared `24 × 13` cell canvas.
Every engine stage provides the complete visual set, revealing horns and folded
wings gradually while preserving the friendly rounded core. Shadow wisps move
slowly, reactions stay short, and reduced-motion mode keeps the first frame.
