# Faísca

## Identity

- Id: `faisca`
- Theme: fire elemental
- Personality: animated, playful, easily bored
- Primary silhouette: rounded ember wrapped by an upward flame
- Primary accent: yellow with orange development accents

## Mandatory visual anchors

- flame-shaped crown with an uneven top edge;
- dark round body inside the flame;
- bright eyes and small curved mouth;
- short feet anchored below the ember;
- sparks confined to the effect margin.

## Stage direction

| Engine stage | Direction                                          |
| ------------ | -------------------------------------------------- |
| `egg`        | Small coal with one pilot flame                    |
| `baby`       | First guide form; compact flame and tiny feet      |
| `child`      | Second guide form; wider flame and active sparks   |
| `teen`       | Leaner, taller flame with fast asymmetrical motion |
| `adult`      | Third guide form; layered yellow-orange blaze      |
| `elder`      | Stable furnace-like flame with slower outer sparks |

Faísca grows through flame complexity rather than losing its compact ember body.
