# Mascot production checklist

A mascot is ready for implementation when:

- [ ] identity, personality, and theme are approved;
- [ ] family silhouette is recognizable in monochrome;
- [ ] the six engine stages are designed;
- [ ] at least two family anchors survive every evolution;
- [ ] every required visual key has a fallback frame;
- [ ] every animation has stable dimensions and baseline;
- [ ] the 24 × 16 cell limit is respected;
- [ ] bundled-font glyph coverage is verified on Windows and macOS;
- [ ] light and dark theme contrast is verified;
- [ ] reduced-motion behavior is defined;
- [ ] status descriptions do not depend on color;
- [ ] manifest completeness tests pass;
- [ ] the mascot is reviewed at `320 × 520` and `360 × 620` logical pixels.
