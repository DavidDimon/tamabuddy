# Nexo

## Identity

- Id: `nexo`
- Theme: digital creature
- Personality: analytical and adaptive
- Primary silhouette: blocky terminal cat with antenna-like ears
- Primary accent: purple

## Mandatory visual anchors

- two tall digital ears or antennae;
- rectangular head and body construction;
- bright rectangular eyes;
- pixel-like mouth;
- data fragments may appear only in the effect margin.

## Stage direction

| Engine stage | Direction                                                   |
| ------------ | ----------------------------------------------------------- |
| `egg`        | Closed data block with a blinking cursor seam               |
| `baby`       | First guide form; head-dominant terminal creature           |
| `child`      | Second guide form; defined body and compact limbs           |
| `teen`       | Taller frame with visible connectors and data tail          |
| `adult`      | Third guide form; reinforced terminal chassis               |
| `elder`      | Stable archive form with broad ears and slower data effects |

Glitches are animation effects, not changes to the underlying sprite dimensions.
