# Codex adapter

`AGENTS.md` points Codex here indirectly through the harness root. For architecture or domain work:

1. read the harness retrieval order;
2. load only rules relevant to the task;
3. enter the engine through its domain README when affected;
4. load the matching skill from `core/skills/index.md`;
5. validate against code and tests.

Do not copy harness rules into Codex-specific files. This adapter translates discovery only; shared guidance remains under `core/` and `domains/`.
